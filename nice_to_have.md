# Nice to Have (Nápady a budoucí rozšíření)

1. **Vizuální minirodokmen na displeji**:
   - Místo pouhého textového řetězce možnost zobrazit interaktivní stromovou grafiku zadaného vztahu.
2. **Režim "Kvíz / Procvičování"**:
   - Trénink znalosti českých (a staročeských) rodinných vztahů formou rychlých otázek.
3. **Reverzní vyhledávač ("Kdo je to...")**:
   - Uživatel vybere slovo (např. *zelva* nebo *ujec*) a aplikace ukáže definici a kroky na kalkulačce, jak k tomuto vztahu dojít.
4. **Hlasové zadávání / čtení výsledku**:
   - Pomocí Web Speech API syntéza řeči pro přečtení názvu vztahu.
5. **Sdílení výsledku**:
   - Tlačítko pro sdílení vypočteného vztahu přes Web Share API nebo zkopírování do schránky jako hezká vizitka.
